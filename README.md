# tbot

> Telegram-бот для анонимной поддержки: вопросы из личных сообщений превращаются в тикеты, обсуждаются в рабочей группе, а итоговые ответы публикуются в канале.

## Возможности

* Приём вопросов в личных сообщениях бота.
* Создание тикета и пересылка вопроса в рабочую группу.
* Сохранение ответов участников группы с их выбранными псевдонимами.
* Закрытие тикета и публикация итоговой переписки в канале с результатами.
* Удаление тикетов и отдельных ответов.
* Блокировка пользователей за спам.

## Требования

* Python 3.10 или новее.
* Бот, созданный через [@BotFather](https://t.me/BotFather).
* Рабочая группа для обсуждения тикетов.
* Канал или чат для публикации закрытых тикетов.

## Установка

Склонируйте репозиторий и создайте виртуальное окружение:

```bash
git clone <адрес-вашего-репозитория>
cd tbot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

На Windows используйте `venv\Scripts\activate` вместо `source venv/bin/activate`.

## Настройка

Бот читает настройки из переменных окружения:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather |
| `TELEGRAM_GROUP_ID` | ID рабочей группы, куда приходят тикеты |
| `TELEGRAM_RESULT_CHAT_ID` | ID канала или чата для закрытых тикетов |

Скопируйте пример файла с переменными и заполните значения:

```bash
cp .env.example .env
```

Затем загрузите переменные перед запуском:

```bash
set -a
source .env
set +a
python main.py
```

На Windows можно задать переменные в текущей сессии PowerShell:

```powershell
$env:TELEGRAM_BOT_TOKEN="..."
$env:TELEGRAM_GROUP_ID="-100..."
$env:TELEGRAM_RESULT_CHAT_ID="-100..."
python main.py
```

### Права бота

Добавьте бота в рабочую группу и канал с правом отправки сообщений. Для корректной работы обработки вступивших участников боту также нужен доступ к обновлениям членства чата. ID чата можно получить, например, переслав сообщение боту [@userinfobot](https://t.me/userinfobot).

## Как работает бот

1. Пользователь отправляет вопрос боту в личные сообщения.
2. Бот сохраняет тикет в SQLite и отправляет вопрос в рабочую группу с кнопками «Закрыть тикет», «Удалить тикет» и «БАН».
3. Участник группы отвечает реплаем на сообщение тикета. Перед этим он задаёт себе псевдоним командой `/nick` или при первом входе в группу.
4. Ответ сохраняется в базе с псевдонимом автора и кнопкой удаления.
5. При закрытии тикета бот собирает вопрос и ответы, публикует их в канале с результатами и помечает тикет закрытым.

## Структура проекта

```text
tbot
├── main.py         # Точка входа и запуск polling-режима
├── config.py       # Чтение настроек из переменных окружения
├── handlers.py     # Обработчики сообщений, команд и кнопок
├── database.py     # Работа с SQLite
├── keyboard.py     # Inline-клавиатуры для тикетов и ответов
└── requirements.txt
```

## Приватность и данные

Бот хранит тикеты, ответы, псевдонимы, Telegram ID и usernames в файле `data.db` в каталоге запуска. Файл базы данных добавлен в `.gitignore`. Не публикуйте его и не передавайте без необходимости, потому что он может содержать личную переписку и идентификаторы пользователей.

## Разработка

Проверьте синтаксис перед коммитом:

```bash
python -m compileall .
```

Проект небольшой и намеренно не использует веб-фреймворки: только `python-telegram-bot` и стандартную библиотеку.
